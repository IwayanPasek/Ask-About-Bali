## AI Model / API / Method
Google Gemini 3.5 Flash-Lite (gemini-3.5-flash-lite)

## Peran AI dalam Produk
Gemini 3.5 Flash-Lite digunakan untuk memahami pertanyaan pengguna atau pilihan kategori dalam konteks Bali. Jika diperlukan, AI menghasilkan instruksi atau kata kunci pencarian. Sistem kemudian melakukan pencarian web atau pencarian gambar melalui Google Programmable Search Engine berdasarkan instruksi tersebut.

Untuk kebutuhan lokasi, sistem menggunakan Google Maps API. Hasil akhir berupa jawaban teks yang dapat dilengkapi gambar, data web, data lokasi, dan tautan menuju sumber asal.

## Dataset / Data Source
Aplikasi tidak menggunakan dataset khusus. Data diperoleh secara dinamis dari web search, image search, dan Google Maps API.
